  штатного перезапуска; сам твик активен по `defaultOn`);

Риски:
- прокси шапки и скрытие поиска — DOM-надстройки на aria/хешах классов;
- фильтр «+» держит подписи en/zh;
- «Copy session ID» зависит от доступа к буферу;
- планшет с открытой правой панелью пересчитывает её трек при раскрытом ящике.

Следующий шаг: обновить страницу на телефоне и пройти чек-лист (меню, чат без
