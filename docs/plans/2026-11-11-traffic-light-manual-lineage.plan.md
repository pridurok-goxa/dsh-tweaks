## 2. Правило, которое вводим

1. При `subagent/start` на сессии родителя, если `stepAutomatic(parent) !== true` (ручной шаг), запоминаем `childId` в `manualChildren` (Map `childId → parentId`, предел 256, FIFO-вытеснение старшего с записью в лог).
2. `classifyMessage`/`classifyBatch`: для видов из `manual`-линейки (`subagent-settled`, `child`, `agent-message`, `team-message`) читаем id отправителя (`source.senderSessionId ?? source.senderId`); если он есть в `manualChildren` → класс `'user'`. Нет id, пустая строка или отправитель неизвестен → как раньше `'auto'`.
3. Цепочка многоуровневая: ручной шаг → субагент A (в памятке) → A порождает B из своего ручного шага (A уже прошёл `pre-step` с `kind:'subagent'` → `autoMode[A]=false` → `stepAutomatic[A]=false`) → B в памятке; итог B → A продолжается на красном; итог A → родитель продолжается на красном.
4. Очистка памяти: запись ребёнка **не** удаляется при `agent/disposed` самого ребёнка (см. F1) — удаляются только записи детей того агента, который выгружается (`forgetManualChildrenOf(parentId)`), плюс предел 256 и `clear()` при `deactivate`.
5. `goal`/`tool-goal` не трогаем (п. 4 поручения, README-строка про отдельную опцию).
